# Start

1. Virtual environment

    1. Create virtual environment (**venv**)
        ```
        python -m venv [path to venv folder]
        ```

    2. Activate **venv**
        ```
        [path to venv folder]\Scripts\activate
        ```

2. Install **requirements**
    ```
    pip install -r requirements.txt
    ```

3. Configure
    ```
    python -m main.configure
    ```

4. Run
    ```
    python -m main.run
    ```
